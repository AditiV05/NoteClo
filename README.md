## 🎯 About

NoteClothing is a fashion e-commerce concept where every product is modeled and rendered in **Clo 3D** — the professional fashion design tool used by brands like Adidas, Zara, and Ralph Lauren. The platform supports user authentication, product browsing, cart management, and integrated payments.

This was a **two-person collaborative project**.

---

## 👩‍💻 My Role

### 🎽 3D Product Modeling (Clo 3D)
Designed and rendered **10 clothing items in Clo 3D** — the entire product catalog for the platform. Work included pattern construction, fabric texturing, garment fitting, and final renders. Clo 3D is an industry-standard professional fashion design tool, and using it for an e-commerce demo brought a level of product realism that placeholder images couldn't.

### 🔐 Authentication & User-Facing Frontend (React)
Built the Login, Signup, and User Profile pages. Implemented form validation, protected route handling, and client-side auth token management.

### 🔌 Frontend ↔ Backend Integration
Wired UI components to backend REST APIs using axios. Managed loading states, error handling, and authenticated request flows.

### 🎨 UI / UX Design
Contributed to overall layout, visual hierarchy, and interaction design decisions across the app.
